## 一、卡牌系统 `CardDef`

```
# CardDef.asset （ScriptableObject）
+--------------+---------------------------------+-----------------------------------+
| 字段         | 类型                            | 说明                              |
+--------------+---------------------------------+-----------------------------------+
| Id           | string                          | 唯一ID，格式 "card_{流派}_{序号}"    |
|              |                                 | 例: "card_fire_01"                |
+--------------+---------------------------------+-----------------------------------+
| Name         | string                          | 展示名称，"灼热打击"                 |
+--------------+---------------------------------+-----------------------------------+
| Cost         | int                             | 费用，范围 0-5                     |
+--------------+---------------------------------+-----------------------------------+
| Type         | enum                            | Attack / Skill / Power            |
+--------------+---------------------------------+-----------------------------------+
| Rarity       | enum                            | Common / Uncommon / Rare          |
+--------------+---------------------------------+-----------------------------------+
| Class        | string?                         | 职业限定，null = 全职业通用          |
|              |                                 | "fire" "ice" "lightning"          |
+--------------+---------------------------------+-----------------------------------+
| Damage       | int                             | 基础伤害，非 Attack 填 0            |
+--------------+---------------------------------+-----------------------------------+
| Block        | int                             | 基础格挡，非 Skill 填 0             |
+--------------+---------------------------------+-----------------------------------+
| Effects      | List<EffectEntry>               | 附加效果列表，可为空                |
+--------------+---------------------------------+-----------------------------------+
| Keywords     | List<string>                    | 检索标签，"fire" "aoe" "scaling"   |
+--------------+---------------------------------+-----------------------------------+
| UpgradeToId  | string?                         | 升级后的卡牌 ID，null = 不可升级     |
+--------------+---------------------------------+-----------------------------------+
| FlavorText   | string                          | 风味文字，斜体展示，可空             |
+--------------+---------------------------------+-----------------------------------+
| Description  | string（自动生成）              | 程序拼接，策划不填                  |
+--------------+---------------------------------+-----------------------------------+
```

### Description 自动生成规则

```
{Cost}费。{Type分支}。{各 Effect.Description}。
  - Attack: "造成{Damage}点伤害。"
  - Skill:  Damage=0 时不写伤害，Block>0 时写"获得{Block}点格挡。"
  - Power:  无 Damage/Block 文本，仅写效果描述。
```

**策划不需要填 Description。** 只需填 Damage/Block/Effects 等字段，程序运行后在 Inspector 里检查生成的文本是否通顺。

### 策划的 Excel 设计表格式

| Id | Name | Cost | Type | Rarity | Class | Damage | Block | Effects（自然语言） | Keywords | FlavorText |
|----|------|------|------|--------|-------|--------|-------|---------------------|----------|------------|
| card_ice_01 | 寒冰箭 | 1 | Attack | Common | ice | 6 | 0 | ApplyStatus(Freeze,2) | ice | 一支由纯冰凝成的箭矢 |
| card_ice_02 | 碎裂 | 2 | Attack | Uncommon | ice | 4 | 0 | IfTargetHasStatus(Freeze,DealDamage,8) | ice conditional | "碎了。" |
| card_fire_01 | 灼热打击 | 2 | Attack | Common | fire | 9 | 0 | | fire | |
| card_neutral_01 | 防御 | 1 | Skill | Common | | 0 | 5 | | basic | |

**Effects 列语法**：用 `FunctionName(Arg1,Arg2)` 格式，多个效果用 ` | ` 分隔。程序写解析器把字符串转为 `List<EffectEntry>`。

## 二、效果原语 `EffectEntry`

```
# EffectEntry（CardDef 和 RelicDef 共用，非 SO，是嵌套结构）
+--------------+-----------------------------------------+---------------------------+
| 字段         | 类型                                    | 说明                      |
+--------------+-----------------------------------------+---------------------------+
| Trigger      | enum                                    | 触发时机                   |
|              | OnPlay / OnTurnStart / OnTurnEnd /      |                           |
|              | OnDamageTaken / OnDamageDealt /         |                           |
|              | OnKill / OnCardDrawn / OnCardDiscarded / |                           |
|              | OnBlockDepleted / OnHpBelow50Percent    |                           |
+--------------+-----------------------------------------+---------------------------+
| Target       | enum                                    | 目标                      |
|              | Self / SelectedEnemy / AllEnemies /      |                           |
|              | RandomEnemy / All / HandPile /          |                           |
|              | DrawPile / DiscardPile / RandomCardInHand|                           |
+--------------+-----------------------------------------+---------------------------+
| Action       | enum                                    | 动作类型                   |
|              | DealDamage / GainBlock / Heal /         |                           |
|              | DrawCards / DiscardCards /              |                           |
|              | ApplyStatus / RemoveStatus /            |                           |
|              | DoubleStatus / ReduceStatusToZero /     |                           |
|              | ExhaustCard / ExhaustRandomCard /       |                           |
|              | ReduceCost / ReduceAllCostsInHand /     |                           |
|              | RandomUpgrade / SpawnCopy /             |                           |
|              | RepeatLastCard / NextTurnDraw /         |                           |
|              | NextTurnEnergy / GainGold /             |                           |
|              | Lifesteal / RetainCard                  |                           |
+--------------+-----------------------------------------+---------------------------+
| Value        | int                                     | 数值                      |
+--------------+-----------------------------------------+---------------------------+
| StatusType   | string?                                 | 仅 ApplyStatus/DoubleStatus|
|              |                                         | /RemoveStatus 时填        |
|              |                                         | "Freeze" "Burn" "Weak"等  |
+--------------+-----------------------------------------+---------------------------+
| Condition    | ConditionEntry?                         | 条件，可为空               |
| Description  | string（自动生成）                      | 如"施加 2 层冻结"          |
+--------------+-----------------------------------------+---------------------------+

# ConditionEntry
+--------------+-----------------------------------------+---------------------------+
| 字段         | 类型                                    | 说明                      |
+--------------+-----------------------------------------+---------------------------+
| Type         | enum                                    |                           |
|              | HasStatus / HpBelow / HpAbovePercent /  |                           |
|              | HasRelic / CardPlayedThisTurnCount /    |                           |
|              | EnemyCountAbove / NoEnemies /           |                           |
|              | LastCardWas / PlayerHpLostThisCombat    |                           |
+--------------+-----------------------------------------+---------------------------+
| Param        | string                                  | 条件参数                   |
|              |                                         | HasStatus: "Freeze"       |
|              |                                         | HpBelow: "50"             |
|              |                                         | HasRelic: "relic_ice_01"  |
+--------------+-----------------------------------------+---------------------------+
```

### 效果原语的 Description 自动生成规则

| Action | 生成模板 |
|--------|---------|
| DealDamage | "造成 {Value} 点伤害" |
| GainBlock | "获得 {Value} 点格挡" |
| Heal | "回复 {Value} 点生命" |
| DrawCards | "抽 {Value} 张牌" |
| DiscardCards | "弃 {Value} 张牌" |
| ApplyStatus | "施加 {Value} 层 {StatusType}" |
| RemoveStatus | "移除 {Value} 层 {StatusType}" |
| DoubleStatus | "{StatusType} 层数翻倍" |
| ExhaustCard | "消耗" |
| ReduceCost | "本场战斗费用 -{Value}" |
| RandomUpgrade | "随机升级手牌中一张牌" |
| SpawnCopy | "将一张复制加入手牌" |
| NextTurnDraw | "下回合额外抽 {Value} 张" |
| NextTurnEnergy | "下回合获得 {Value} 点能量" |

条件前缀模板：`如果` + 条件描述 + `，` + 效果描述。例：`"如果目标有冻结，造成 8 点伤害"`

## 四、敌人系统 `EnemyDef`

```
# EnemyDef.asset
+--------------+---------------------------------+-----------------------------------+
| 字段         | 类型                            | 说明                              |
+--------------+---------------------------------+-----------------------------------+
| Id           | string                          | "enemy_wolf_01"                   |
+--------------+---------------------------------+-----------------------------------+
| Name         | string                          | "霜牙猎犬"                         |
+--------------+---------------------------------+-----------------------------------+
| MaxHp        | int                             | 最大生命值                         |
+--------------+---------------------------------+-----------------------------------+
| IntentPool   | List<EnemyIntent>               | 从池中按权重选择行动                |
+--------------+---------------------------------+-----------------------------------+
| StartingStatus| List<StatusApply>               | 战斗开始时自带的状态，"Block:10"    |
+--------------+---------------------------------+-----------------------------------+
| Keywords     | List<string>                    | "beast" "ice"                     |
+--------------+---------------------------------+-----------------------------------+
| FlavorText   | string                          | 出场时显示的观察文本                |
|              |                                 | "它的獠牙上凝结着冰霜"              |
+--------------+---------------------------------+-----------------------------------+

# EnemyIntent
+--------------+---------------------------------+-----------------------------------+
| 字段         | 类型                            | 说明                              |
+--------------+---------------------------------+-----------------------------------+
| Type         | enum                            | Attack / Defend / Buff / Debuff / |
|              |                                 | Summon / Special                  |
+--------------+---------------------------------+-----------------------------------+
| Value        | int                             | 伤害值 / 格挡值                    |
+--------------+---------------------------------+-----------------------------------+
| Count        | int                             | 连击次数，单次=1                   |
+--------------+---------------------------------+-----------------------------------+
| Effects      | List<EffectEntry>               | 附加效果                          |
+--------------+---------------------------------+-----------------------------------+
| Weight       | float                           | 选择权重（相对值，不是百分比）       |
+--------------+---------------------------------+-----------------------------------+
| MinRound     | int                             | 此行动可用的最小回合数（1-based）    |
+--------------+---------------------------------+-----------------------------------+
| Cooldown     | int                             | 使用后的冷却回合数，0 = 无冷却       |
+--------------+---------------------------------+-----------------------------------+
| Condition    | string                          | "HP<50%" "HasStatus:Freeze"       |
+--------------+---------------------------------+-----------------------------------+
| PreviewText  | string（自动生成）              | "攻击 8×2" / "防御 12" / "强化"    |
+--------------+---------------------------------+-----------------------------------+
```

### PreviewText 自动生成

| Type | 模板 |
|------|------|
| Attack + Value + Count | "攻击 {Value}×{Count}" |
| Attack + 0 伤害 + 有 Effect | "施法"（显示 Effect 描述） |
| Defend + Value | "防御 {Value}" |
| Buff | "强化" |
| Debuff | "削弱" |
| Summon | "召唤" |
| Special | "特殊行动" |

## 十一、对话剧本格式（Markdown）

策划用 Markdown 写对话原稿，程序写脚本解析生成 `DialogueSequence` SO。

### Markdown 语法规范

```markdown
# 对话标题 / dialogue_id

> 元信息：触发条件 / 前置对话 / 备注

---

[speaker_id, 立绘位置, 表情]
对话正文第一行
可以换行写第二行（同一角色连续说话）

[narrator]
旁白/叙述文本

> CHOICE                    ← 选择分支标记

- [标签] "选项文本" → goto: 目标标签
- [标签2] "选项文本2" → goto: 目标标签2
- （选项3不加标签）→ goto: 目标标签3

> CONDITION: has_relic:badge   ← 条件选项标记（紧跟在 - 后的行）

---

## 目标标签               ← 标签行（以 ## 开头）

[speaker_id, 立绘位置, 表情]
选择后的对话内容

> REWARD: relic_scroll_01      ← 奖励指令
> PENALTY: lose_gold:50        ← 惩罚指令
> CHAIN: event_wounded_02      ← 触发后续事件
> END_DIALOGUE                 ← 结束对话
```

### 语法规则

| 语法 | 含义 |
|------|------|
| `# 标题 / id` | 对话标题和 ID，`/` 后面是 DialogueSequence.Id |
| `> 元信息` | 注释行，不生成内容，仅供人读 |
| `---` | 分隔符，标记对话正文开始 |
| `[speaker_id, position, emotion]` | 一个对话行：说话人 / 立绘位置 / 表情 |
| `[narrator]` | 旁白（无说话人、无立绘） |
| `> CHOICE` | 选择分支开始，后续 `-` 行是选项 |
| `- [tag] "text" → goto: label` | 选项定义 |
| `> CONDITION: xxx` | 上一行的选项显示条件 |
| `## label` | 跳转标签，Choice 的 goto 目标 |
| `> REWARD: type:value` | 奖励：`gold:100` / `card:card_fire_01` / `relic:relic_ice_01` / `heal:30` / `upgrade_card:any` |
| `> PENALTY: type:value` | 惩罚：`lose_gold:50` / `lose_hp:20` / `add_curse:curse_01` |
| `> CHAIN: event_id` | 触发后续事件 |
| `> END_DIALOGUE` | 对话结束 |

### 完整示例

```markdown
# 酒馆闲聊 / dialogue_tavern_01

> 触发条件：首次进入酒馆事件节点
> SpeakerDef 关联：elder_chen, player

---

[elder_chen, Center, neutral]
冒险者。你身上有"那个东西"的气味。

[narrator]
老人放下酒杯。他的右眼是灰白色的，看不见东西，但左眼盯着你。

[player, Left, neutral]
我不懂你在说什么。

[elder_chen, Center, narrow_eyes]
你当然不懂。但你背包里的碎片知道。

> CHOICE

- [强硬] "离我远点。" → goto: threatening
- [试探] "你说的碎片是什么？" → goto: explain
- [沉默] （不说话，盯着老人） → goto: silent

---

## threatening

[elder_chen, Center, sigh]
如你所愿。

[narrator]
老人起身离开。你注意到他坐过的椅子下面压着一张泛黄的纸条。

> REWARD: relic:relic_scroll_01
> END_DIALOGUE

---

## explain

[elder_chen, Center, slight_smile]
冰霜碎片。永冻核心的遗物。你手里那个，是第三块。
也是最后一块。

[player, Left, surprised]
你怎么知道——

[elder_chen, Center, neutral]
因为我曾经是它的主人。

> END_DIALOGUE

---

## silent

[elder_chen, Center, neutral]
不说话的人有两种。
一种是什么都不知道，一种是什么都知道但不敢说。
你是哪一种？

> CHOICE

- [诚实] "第一种。" → goto: explain
- [撒谎] "关你什么事。" → goto: threatening
```

### 解析器的职责

1. 读取 `.md` 文件
2. 以 `---` 和 `##` 为界分割段落
3. `[speaker, pos, emotion]` 行 → `DialogueLine`
4. `> CHOICE` → 后续 `- [tag] "text" → goto: label` → `DialogueChoice`
5. `> REWARD:` / `> PENALTY:` → `OnSelectEffects`
6. `goto:` 目标 → 查找对应的 `## label` → 设置 `NextLineIndex`
7. 输出 → `DialogueSequence.asset`，存到 `Assets/Resources/Dialogue/`
